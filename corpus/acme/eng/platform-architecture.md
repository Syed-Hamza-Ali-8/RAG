# Atlas Platform Architecture

## Overview

Atlas is Acme's managed analytics platform. It ingests client operational data, models it in a warehouse and serves dashboards to client users. The platform is owned by the Cloud Advisory practice; the technical owner is Mei Lin Zhou, Chief Technology Officer.

## Hosting

Atlas runs on Cobalt Cloud. The primary region is Frankfurt and the secondary (disaster recovery) region is Dubai. Cobalt Cloud is contracted under enterprise agreement CC-ENT-4471. UK healthcare workloads that must stay in the UK run in a separate deployment in Cobalt Cloud's London region.

## Components

- Ingestion workers running on Kubernetes pull data from client systems every 15 minutes.
- A managed PostgreSQL 16 cluster stores the modelled data. It replicates asynchronously to the Dubai region.
- The dashboard service serves client users and authenticates them through single sign-on (SSO).
- Grafana Cloud provides metrics, logs and alerting.
- Invoices for Atlas subscriptions are generated by Ledgerline, which reads monthly usage from the Atlas billing export.

## Availability Targets

Atlas commits to 99.5% monthly availability for clients. The internal recovery targets are a recovery point objective (RPO) of 5 minutes and a recovery time objective (RTO) of 30 minutes. These depend on Cobalt Cloud meeting its own 99.9% commitment.

## Deployment

Code is hosted in GitHub Enterprise and deployed by GitHub Actions. Production deployments need one approving review and run only between 10:00 and 16:00 PKT on weekdays.

## Security

All data is encrypted at rest and in transit. Production access requires SSO with hardware-key MFA. Access is reviewed quarterly by the platform team.
